# انتشار ۲ نوامبر ۲۰۲۶ — مهاجرت به 3x-ui 3.11.0

## پایه نسخه و ساخت
- upstream: MHSanaei/3x-ui v3.11.0, commit c621ba9014a6aa21fd7c9ecf45655e44e24ebf13.
- toolchain: Go 1.27.3, Node.js 26.13.0.
- Patch اختصاصی: ۳۳ فایل؛ شامل صفحات native فروش، OpenVPN، OpenConnect، بکاپ/بازیابی، APIهای اختصاصی و مسیرهای subscription VPN.
- TypeScript tsc --noEmit موفق؛ Vite production build موفق؛ go build باینری اختصاصی حدود ۱۰۲MB ساخت.
- تست Go برای internal/web/service/panel, internal/web/controller, internal/sub موفق.
- تست‌های بکاپ v2 شامل رمزگذاری، سه دیتابیس، restore ایزوله، Local Telegram Bot API، cache رسانه، --skip-media، inventory سرویس‌ها و ترتیب stop/start موفق.
- باینری جدید هنوز روی x-ui فعال نصب نشده است.

## حفاظت از self-update
Updater رسمی 3x-ui از update.sh رسمی استفاده می‌کند و باینری بدون Patch را جایگزین می‌کند. در build مسیحا:
- GetUpdateInfo به‌روزرسانی رسمی را advertise نمی‌کند.
- StartUpdate و StartUpdateChannel با پیام محافظتی رد می‌شوند.
- ارتقا فقط از Git، اعمال Patch، build و تعویض کنترل‌شده انجام می‌شود.
منوی sidecar در Nginx مستقل است؛ native pages/APIها به باینری Patch‌شده نیاز دارند.

## بکاپ کامل v2
- سه دیتابیس SQLite با integrity check.
- /etc/openvpn/masiha و masiha-ros6، OpenConnect، strongSwan/IKEv2، L2TP، SSTP/accel-ppp، Nginx/TLS، systemd، helperها و فایل‌های runtime.
- Local Telegram Bot API: config، binary، user/group tgbotapi و /var/lib/telegram-bot-api.
- audio fingerprint index، media database و وضعیت سرویس‌ها/timers.
- service inventory شامل strongSwan، xl2tpd، هر دو OpenVPN، ocserv، SSTP، x-ui، sidecar، Nginx، certbot renewal، Local Bot API و worker/timerهای media.
- manifest نسخه‌ها و وضعیت نصب‌شدن ۱۰۵۰ بسته Debian را ثبت می‌کند؛ بسته‌های لازم برای سرویس‌های فعال و فایل‌های حیاتی قبل از backup/restore بررسی می‌شوند.
- workerهای Telegram/media روی مقصد تا cutover دستی پس از توقف مبدأ غیرفعال می‌مانند.
- بکاپ وب پنل عمداً --skip-media است و فقط بکاپ سبک محسوب می‌شود؛ برای مهاجرت کامل از CLI v2 و SCP/SFTP استفاده شود.

## وضعیت عملیاتی
سرور زنده همچنان روی x-ui 3.8.5 باقی مانده است؛ هیچ باینری جدیدی روی سرویس فعال جایگزین نشده. ارتقای عملیاتی پس از اتمام تست‌ها، گرفتن بکاپ کامل v2 و تأیید پنجره نگهداری انجام می‌شود. نصب صفر تا صد روی VPS جدید و مهاجرت واقعی به مقصد هنوز باید جداگانه تأیید شود.

## اصلاحات نصب واقعی روی سرور جدید (۲ نوامبر)

- تست نصب اولیه نشان داد قطع SSH بعد از جایگزینی باینری و قبل از دریافت SSL ممکن است مراحل ناتمام بگذارد؛ اسکریپت resumable و fail-closed جداگانه اضافه شد.
- فایل‌های Python مرتبط با فیلم و پیام بازیابی عضویت که در نصب تازه جا افتاده بودند در runtime نصب می‌شوند.
- Nginx sidecar routeها قبل از patchهای legacy تزریق می‌شوند تا fresh install به خاطر missing anchor متوقف نشود.
- تست jsdom منوی مسیحا دیگر مسیر build قدیمی 20261011 را استفاده نمی‌کند.
- نمایش رمز عبور در خروجی نصب غیرفعال و رمز اولیه فقط در فایل root-only باقی می‌ماند.
- نصب آزمایشی روی IP 178.83.46.90 و دامنه s2.chanelchat.ir موفق شد؛ HTTPS و سرویس‌های x-ui، OpenVPN، OpenConnect، sidecar و ۱۴ inbound آزمایش شدند.
- این نصب هنوز خالی از اطلاعات مشتریان قبلی است؛ انتقال آرشیو GPG نسخه ۲ و آزمون بازیابی پس از قطع پردازشگرهای Telegram مبدأ مرحله جداگانه است.
