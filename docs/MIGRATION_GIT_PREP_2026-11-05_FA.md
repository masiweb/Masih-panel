# آماده‌سازی مهاجرت VPN Manager از Git

این شاخه برای نصب یا به‌روزرسانی ساختار نرم‌افزار سرور جدید آماده شده است؛
اجرای نصب اولیه روی میزبان دارای x-ui فعال ممنوع است. ابتدا وضعیت
سرور مقصد، فایل‌های نسخه بازگشت، و گزارش اعتبارسنجی مهاجرت را بررسی کنید.

## موارد موجود در Git
- فایل‌های برنامه VPN، ربات فروش و ماژول‌های فیلم و موزیک، به‌همراه IPsec و لاگ مدیریتی AI.
- سرویس پاک‌سازی کش Telegram Local Bot API و آزمون‌های مرتبط.
- پنل مدیریت فیلم و مسیر API آن در sidecar.
- نصب افزایشی فیلم با حالت استقرار ایمن:
  MASIHA_MIGRATION_STAGING=1 bash deploy/install-film-import.sh
  در این حالت آپلود فیلم و اجرای ربات شروع نمی‌شود.

## موارد عمداً خارج از Git
- دیتابیس‌های واقعی sales.db و users.db و x-ui.db و اطلاعات کاربران،
  رمزها، کلیدهای TLS، شناسه‌های فایل‌ها و توکن تلگرام.
- فایل‌های اثرانگشت صوتی، بکاپ‌های رمزگذاری‌شده و فایل رمزگشایی.
- کش موقت صوت و ویدیو و داده‌های چندگیگابایتی Local Bot API.

این داده‌ها باید از بکاپ رمزگذاری‌شده جداگانه و به‌صورت کنترل‌شده روی مقصد بازیابی شوند.
بکاپ کم‌حجم masiha-compact-migration-20261105.tar.gz.gpg
دارای قالب اختصاصی است و نباید به دستور full_backup.py restore داده شود.

## قبل از فعال‌سازی ربات روی سرور جدید
۱. سرویس‌های ربات و واردکننده رسانه روی مقصد خاموش بمانند.
۲. ابتدا دیتابیس‌ها و تنظیمات نسخه مقصد را با بکاپ و مخزن تطبیق دهید.
۳. سلامت همه SQLite‌ها و اتصال X-UI، VPN و Local Bot API را آزمایش کنید.
۴. چون سرور قدیمی هنوز فعال است، پس از توقف کنترل‌شده پردازشگرهای آن
   یک بکاپ/همگام‌سازی نهایی از تغییرات جدید گرفته شود.
۵. تا زمانی که تأیید نشده ربات مبدأ دیگر polling و outbox را انجام نمی‌دهد،
   ربات مقصد نباید شروع به کار کند.
۶. تایمرهای آپلود فیلم فعلاً غیرفعال بمانند؛ شروع آن‌ها نیازمند تصمیم جداگانه است.

از ذخیره رمزها و توکن‌ها در Git یا لاگ‌های عمومی خودداری کنید.
