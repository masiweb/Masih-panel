## Prioritized next features / limitations

1. Real cross-protocol traffic tests (OpenVPN, OpenConnect and Xray) including exhaustion and disconnect, not just synthetic service provisioning.
2. Real end-to-end fresh Ubuntu 24.04 installation of the updated installer and external-domain subscription URLs.
3. Payment gateway live/sandbox verification, chargeback/refund reconciliation and audit trail. Zarinpal live payment has not been exercised by this release test.
4. Bot negative network conditions / concurrent polling tests and Telegram outbound error taxonomy; actual SMS/Telegram notifications to arbitrary customers are not tested.
5. Automatic encrypted off-server backup and guarded restore; multi-server/multi-node deployment, access logging and security hardening.
6. Legacy independent OpenVPN/OpenConnect plan quota (currently prohibited in sales UI) is not the same as synchronized quotas for native Xray clients. Don't advertise independent legacy plans as unified-quota.
