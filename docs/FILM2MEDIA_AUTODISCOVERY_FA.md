# واردسازی خودکار Film2Media در Masiha — ۲۰۲۶/۱۰/۲۷

## رفتار قابل اتکا
- سایت `https://www.f2mgo.top/` و مقالات عمومی خوانده می‌شوند. HexDL در مسیر ورود جدید استفاده نمی‌شود.
- شناسه مقاله، عنوان، سال، ژانرهای داخل صفحه، توضیح، تصویر جلد و لینک‌های ویدیویی استخراج می‌شوند. اطلاعاتی که در صفحه وجود ندارند (مانند کارگردان، بازیگران یا امتیاز معتبر) جعل نمی‌شوند.
- کیفیت‌های یک فیلم در یک عنوان واحد با دکمه‌های مجزا ذخیره می‌شوند: 480p، 720p، 1080p، کدک x265 / 10bit، دوبله فارسی و زیرنویس فارسی چسبیده.
- فایل‌های صوتی مستقل MKA، زیرنویس جداگانه و موارد تکراری وارد صف فیلم نمی‌شوند.
- اندازه هر نسخه با HEAD بررسی می‌شود؛ فقط نسخه‌های کوچک‌تر از `1_950_000_000` بایت صف می‌شوند. نسخه‌های بزرگ‌تر در گزارش `skipped` ثبت می‌شوند، بدون دانلود کامل.
- فایل‌های MKV هنگام ارسال به تلگرام با پسوند اصلی MKV آپلود می‌شوند، نه MP4 جعلی.
- نوتیفیکیشن کاربران فقط بعد از آپلود موفق **اولین نسخه** یک عنوان، با همان دکمه مشاهده فیلم، ایجاد می‌شود؛ اضافه‌کردن نسخه‌های دیگر برای همان عنوان اعلان دوباره نمی‌فرستد.
- موقت‌ها بعد از موفقیت یا خطا حذف می‌شوند؛ دیتابیس شناسه پایدار `file_id` را ذخیره می‌کند.

## منبع و مجوز
آدرس عمومی سایت به‌خودی‌خود حق بازنشر فایل‌ها را نمی‌دهد. فایل `/etc/masiha-vpn-extension/sales/film_approved_ids.json` فهرست شناسه پست‌هایی است که صاحب سامانه مجوز بازنشرشان را بررسی و تأیید کرده است. مقدار اولیه آن `[]` است؛ هیچ پستی خودکار تأیید نشده.

مثال محتوای این فایل **فقط در صورت داشتن مجوز بازنشر**:

```json
["88304"]
```

تایمر `masiha-film-discover.timer` هر ساعت ده مطلب تازه را بررسی می‌کند و متادیتای آن‌ها را در `/var/tmp/masiha-films/latest.json` نگه می‌دارد. از میان آن‌ها فقط پست‌های فهرست تأییدشده به صف وارد می‌شوند. دوباره‌دیدن پست صف و اعلان تکراری ایجاد نمی‌کند.

## آزمون نمونه
```bash
cd /opt/masiha-vpn-extension
python3 film2media_discovery.py --page https://www.f2mgo.top/88304/tenzing-2026/ --output /var/tmp/masiha-films/tenzing-preview.json
python3 film_importer.py status
systemctl status masiha-film-discover.timer masiha-film-import.timer
```

بدون `--rights-approved` یا تأیید در allowlist صرفاً متادیتا استخراج می‌شود. اجرای دستی با مجوز مشخص برای یک صفحه:

```bash
python3 film2media_discovery.py --page https://www.f2mgo.top/88304/tenzing-2026/ --stage --rights-approved
```

## محدودیت تلگرام
برای آپلود فایل‌های بزرگ‌تر از ۵۰ مگابایت، سرور رسمی محلی Bot API با `--local` و کلیدهای شخصی `api_id` و `api_hash` لازم است. کلیدها باید بیرون از Git، در فایل امن سرویس نگهداری شوند. پرچم `local_bot_api` در `film_import.json` فقط بعد از روشن‌شدن موفق سرور محلی و تست اتصال باید `true` شود. سقف رسمی آپلود محلی ۲۰۰۰ مگابایت است؛ واردکننده حاشیه امن ۱۹۵۰ مگابایت را اعمال می‌کند.

## مشخصات تأییدشده نمونه Tenzing
ده فایل ویدیویی مستقیم در صفحه فیلم وجود داشت که ۷ نسخه زیر ۱۹۵۰ میلیون بایت بودند. ۳ نسخه بالای سقف بوده و عمداً وارد صف نمی‌شوند. منبع دانلود `abrtech.top` به CDN مجاز `sjdcbjdhbscjnhsdjcbjsd.mehracdn.com` منتقل می‌شود؛ این نام میزبان دقیق باید در `download_hosts` باشد. انتقال CDN به میزبان دیگری بدون بررسی و افزودن به فهرست مجاز پذیرفته نیست.
