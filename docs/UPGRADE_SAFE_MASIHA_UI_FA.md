# مدیریت مستقل مسیحا در کنار پنل رسمی 3x-ui سنایی

منوی مستقل و رابط /masiha-ui/ از باینری x-ui جدا هستند؛ اما صفحات/APIهای native فروش، VPN و بکاپ در Patch باینری قرار دارند. تعویض باینری رسمی، این بخش‌های native را حذف می‌کند.

آدرس پنل سنایی: https://exon.chanelchat.ir/xui/

آدرس ماژول مسیحا: https://exon.chanelchat.ir/masiha-ui/

در صفحه سنایی، میانبر شناور «مدیریت مسیحا» با Nginx تزریق شده است.
برای دسترسی به آن مدیر باید ابتدا در پنل رسمی وارد شود. سرویس مستقل نشست
و توکن CSRF را به‌صورت مستقیم از پنل داخلی x-ui بررسی می‌کند. برای
جلوگیری از اشتباه نقش، فعلاً فقط پنلی با یک کاربر مدیر شناسه ۱ را می‌پذیرد.

## نصب و تعمیر

در این سرور از ریشه گیت پروژه این فرمان‌ها اجرا می‌شوند:

    cd /root/Masih-panel
    sudo bash deploy/install-sidecar.sh
    sudo systemctl status masiha-vpn-sidecar.service
    sudo nginx -t

اسکریپت نصب، فایل اجرایی x-ui را دست نمی‌زند. پیش‌نیاز آن
سورس پروژه شخصی در /opt/masiha-vpn-build-v3.11.0/src/frontend
و ابزارهای Node.js 26.13.0 نصب‌شده توسط نصب‌کننده اصلی است. UI در
/var/www/masiha-ui و API در
/opt/masiha-vpn-extension/sidecar_server.py اجرا می‌شوند.
هیچ کلید یا دیتابیس محرمانه‌ای در Git ذخیره نمی‌شود.

برای مهاجرت به سرور جدید ابتدا نصب Git نسخه 3.11.0 و سپس دستور بالا اجرا می‌شود. دکمه self-update رسمی x-ui در build مسیحا عمداً مسدود است؛ چون updater رسمی باینری بدون Patch را جایگزین می‌کند. برای ارتقا فقط از branch/release گیت و deploy/build-3x-ui.sh استفاده کنید.

## مصرف و انقضا

کد قبلی به API سفارشی Go در x-ui با نام masiha-reconcile
وابسته بود. این API در نسخه رسمی 3.10.2 نیست. آداپتر Python اکنون
شمارنده OpenVPN/OpenConnect را مستقیم به دیتابیس مشترک
client_traffics وارد می‌کند؛ مدیریت مصرف و انقضای همین VPNها
با داده مشترک صورت می‌گیرد. x-ui نیز چرخه طبیعی ترافیک Xray خود را
انجام می‌دهد و ممکن است زمان کوتاهی بین دو بررسی وجود داشته باشد.

## بکاپ کامل

بکاپ وب، دیتابیس‌ها و تنظیمات محرمانه و کل ماژول مستقل وب را
در آرشیو رمزگذاری‌شده .gpg ذخیره می‌کند؛ کلید رمز جداگانه است.
فایل‌های رسانه‌ای ربات به‌صورت پیش‌فرض در بکاپ وب نیستند.

## ماندگاری منوی مدیریت مسیحا در بروزرسانی‌ها

منوی مستقل مسیحا اکنون واقعاً در ساختار فهرست کناری پنل رسمی x-ui قرار
می‌گیرد (پس از کاربران). این قابلیت یک افزودنی سمت مرورگر است و از طریق
Nginx به HTML نسخه رسمی افزوده می‌شود. بنابراین تغییر فایل اجرایی x-ui
منوی سفارشی یا مدیریت اختصاصی را حذف نمی‌کند.

فایل‌های افزونه در /var/www/masiha-ui/nav.js و nav.css هستند و هیچ
فایل داخلی پنل رسمی برای نمایش منو ویرایش نمی‌شود. منو با رندر دیرهنگام
React، تغییر مسیر داخلی، باز شدن منوی موبایل و ساخت مجدد منوی کناری
سازگار شده است. اگر ساختار منو در نسخه آینده ناشناخته باشد، یک لینک
پشتیبان برای ورود به مدیریت مسیحا باقی می‌ماند.

برای عیب‌یابی یا کنترل بعد از بروزرسانی:

    cd /root/Masih-panel
    sudo bash deploy/verify-sidecar-menu.sh

اگر تنظیمات Nginx به‌صورت دستی پاک یا در نصب مجدد تغییر داده شده باشد،
می‌توان افزودنی را بدون تغییر نسخه x-ui بازنصب کرد:

    sudo bash deploy/install-sidecar.sh

توجه: افزودنی در مسیر HTTPS دامنه و از پشت Nginx نمایش داده می‌شود؛
ورود مستقیم با پورت داخلی x-ui باعث دور زدن نقطه تزریق منو می‌شود.
