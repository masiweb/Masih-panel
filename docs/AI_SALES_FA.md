# فروش اشتراک هوش مصنوعی

مسیر کاربر: خرید جدید ← VPN (بدون تغییر) یا هوش مصنوعی.
شاخه هوش مصنوعی: داخل ربات / ایمیل شخصی / ایمیل آماده.

- داخل ربات: انتخاب مدل و پلن، پرداخت کارت‌به‌کارت (رسید، تأیید نهایی و مدیر) یا پرداخت مستقیم از کیف پول (تحویل فوری)، فعال‌سازی سهمیه‌های متن/تصویر/ویدیو.
- ایمیل شخصی: انتخاب مدل و پلن، ثبت ایمیل، پرداخت، ارسال رسید، تأیید نهایی مشتری، تأیید یا رد با ذکر علت توسط مدیر، ثبت وضعیت در حال فعال‌سازی، اعلام موفقیت پس از تکمیل دستی توسط مدیر.
- ایمیل آماده: انتخاب مدل و پلن، پرداخت و رسید، تأیید مشتری و مدیر، تحویل خودکار کد فعال‌سازی رسمی و استفاده‌نشده.

امنیت: رمز حساب/ایمیل از تلگرام گرفته نمی‌شود؛ فعال‌سازی روی ایمیل شخصی با مجوزدهی رسمی سرویس و هماهنگی مدیر انجام می‌شود. موجودی آماده فقط کد ووچر است، نه اطلاعات ورود افراد.

مدیریت: ربات فروش ← فروش هوش مصنوعی. مدیر مدل، نام پلن، نوع، قیمت تومان، مدت، سهمیه‌های استفاده متن/تصویر/ویدیو، انبار کد آماده و تأیید/رد رسید با علت را تعیین می‌کند.

رسانه: متن از اتصال Chat Completions قبلی؛ تصویر ایجاد/ویرایش از API تصاویر OpenAI؛ ویدیو ۸ثانیه‌ای از API ویدیوی OpenAI، با امکان ارسال ویدیوی ورودی تا ۱۰ ثانیه برای ویرایش (دسترسی خاص مدل ممکن است ضروری باشد). قیمت هر نوع استفاده جداگانه است. صف پردازش جدا اجرا می‌شود. هزینه سهمیه/امتیاز فقط پس از تحویل موفق فایل به کاربر کسر می‌شود.

فعال‌سازی رسانه به کلید واقعی OpenAI با مجوز مدل نیاز دارد؛ در نصب اولیه خاموش است. فایل‌های ارسالی و خروجی دائماً روی سرور نگهداری نمی‌شوند.

نصب سرویس رسانه: bash deploy/install-ai-media.sh
