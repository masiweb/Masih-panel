# متن‌های قابل‌ویرایش ربات و منوی تک‌پیامی

## ویرایش بدون تغییر سورس
متن‌های اصلی ربات و دکمه‌ها اکنون در فایل JSON قابل تغییر هستند. نسخه پیش‌فرض سورس:
\`runtime/bot_texts.fa.json\`
و نسخه شخصی‌سازی‌شده ماندگار روی سرور:
\`/etc/masiha-vpn-extension/sales/bot_texts.fa.json\`

فایل سرور در اولویت است و با به‌روزرسانی سورس پاک نمی‌شود. ربات تغییرات را از روی زمان و حجم فایل به‌طور خودکار می‌خواند؛ نیاز به restart نیست.

بخش‌های اصلی فایل:
- \`messages\`: متن کامل یک پیام ثابت (کلید متن پیش‌فرض و مقدار متن جایگزین).
- \`buttons\`: عنوان دکمه‌ها، بدون تغییر \`callback_data\` و پیوندها.
- \`phrases\`: عبارت‌های کوتاه در پیام‌های دارای قیمت، تعداد، نام کاربر و سایر داده‌های پویا. فقط مقدار را تغییر دهید و به متغیرها، URL، اعداد یا شناسه‌ها آسیب نزنید.

برای تولید یا به‌روزرسانی فهرست جامع از روی سورس فعال، بدون پاک‌کردن تغییرات قبلی:

\`\`\`bash
sudo python3 /opt/masiha-vpn-extension/bot_texts_export.py /etc/masiha-vpn-extension/sales/bot_texts.fa.json
\`\`\`

برای ویرایش از \`sudo nano /etc/masiha-vpn-extension/sales/bot_texts.fa.json\` استفاده کنید. قبل از هر تغییر یک نسخه کپی بگیرید. JSON باید UTF-8 معتبر بماند:
\`\`\`bash
sudo python3 -m json.tool /etc/masiha-vpn-extension/sales/bot_texts.fa.json >/dev/null
\`\`\`

تغییر متن‌ها در پنل وب (جدول \`message_templates\`) همچنان فعال است. متن‌های سفارشی پنل در مرحله تولید پیام اعمال می‌شوند و سپس جایگزینی‌های فایل روی متن خروجی انجام می‌گیرد. فایل فقط متن نمایش و caption و عنوان دکمه را تغییر می‌دهد؛ شناسه و callback دکمه، URL، قیمت واقعی، داده‌های فروش و منطق ربات را تغییر نمی‌دهد. جایگزین‌های عمومی \`phrases\` ممکن است بخشی از متن پویا یا متن بازنشرشده را نیز تغییر دهند؛ بنابراین برای عبارت‌های خاص، از کلیدهای طولانی و اختصاصی استفاده کنید.

اگر فایل خطای JSON داشته باشد، ربات پیام‌های اصلی سالم را نمایش می‌دهد. برای بازنشانی یک متن، مقدار راست را برابر کلید چپ کنید یا آن مورد را از فایل حذف نمایید.

## رفتار منوها
با فشردن دکمه اینلاین، پیام منوی قبلی در همان پیام با \`editMessageText\` به‌روزرسانی می‌شود و پیام‌های زیر هم جمع نمی‌شوند. برای دکمه‌های زیر تصاویر و ویدیوها، رسانه نگه داشته و صفحه‌کلید قدیمی مخفی می‌شود. اگر تلگرام ویرایش را رد کند، ربات از ارسال پیام جدید به‌عنوان مسیر جایگزین استفاده می‌کند؛ خطاهای موقت شبکه همچنان قابل تلاش دوباره هستند.

این تغییر روی پیام‌های **جدید** اثر دارد؛ پیام‌های قدیمی تلگرام به‌صورت انبوه پاک نمی‌شوند و رسانه‌ها، فایل‌های کانفیگ، رسیدها و سابقه گفتگو حذف نمی‌شوند.
