# انتخاب سه مدل مستقل برای هر پلن هوش مصنوعی

## مدل‌های پردازش
هر پلن «داخل ربات» دارای `model_text`، `model_image` و `model_video` مستقل است. این سه فیلد در Snapshot سفارش ذخیره می‌شوند تا تغییر بعدی قیمت یا پلن، اشتراک فعال کاربر را تغییر ندهد. مدل‌های قدیمیِ فاقد این فیلدها از تنظیمات قبلی ربات استفاده می‌کنند.

- **OpenAI:** GPT-6 Luna، GPT-6.1 Sol و Astra برای متن؛ GPT Image 2، Flare، Sunburst و Image 1 Mini برای تصویر. اشتراک ChatGPT اعتبار API نیست؛ پرداخت API جداگانه است.
- **Google Gemini:** Gemini 3.8 Flash و 3.5 Flash Lite برای متن، با سهمیه رایگان مشروط به حساب و منطقه.
- **Groq:** GPT-OSS 20B و Llama 3.3 برای متن؛ مدل‌های موجود و سهمیه رایگان تابع شرایط سرویس هستند.
- **Cloudflare Workers AI:** مدل‌های Gemma و GLM برای متن و FLUX.1 Schnell برای تولید تصویر. سهمیه رایگان محدود ۱۰هزار Neurons در روز و سقف‌های دیگر ممکن است تغییر کنند. برای ویرایش تصویر ورودی از OpenAI استفاده شود؛ مدل FLUX موجود فقط متن به تصویر است.
- **fal.ai:** Wan 2.2 و Kling 3.0 برای متن به ویدیوی کوتاه؛ **پولی** و نیازمند کلید مجزا. مدل‌های این مسیر هنوز ویرایش فایل ویدیویی ورودی را ارائه نمی‌کنند. Sora 2/OpenAI Videos API در سپتامبر ۲۰۲۶ حذف شده و در کاتالوگ فعال نیست.

«سهمیه رایگان» یعنی امکان استفاده محدود طبق سیاست شرکت و **نه استفاده همیشگی، بدون کلید یا بدون هزینه احتمالی**. مدل ویدیوی ابری رایگان نامحدود و دارای تضمین دسترسی در این نسخه وجود ندارد؛ مدل‌های متن‌باز محلی نیز نیازمند GPU و منابع پردازش هستند.

## پنل وب
در «فروش هوش مصنوعی»، بخش **فهرست مدل‌های AI و کلید سرویس‌ها** اضافه می‌شود. کلید API ارائه‌دهندگان از پنل مدیر ارسال می‌شود و فقط «کلید تنظیم شده/نشده» برگردانده می‌شود. شناسه حساب Cloudflare جداست. سه انتخاب «مدل پیش‌فرض» برای کاربران بدون اشتراک و مدیر در نظر گرفته شده است.

در فرم «پلن داخل ربات» سه Select مستقل برای مدل متن/تصویر/ویدیو و سه سهمیه مستقل وجود دارد. مدل‌های غیرفعال از Select مخفی می‌شوند. انتخاب مدل در Snapshot هنگام سفارش محفوظ می‌ماند.

## امنیت و نصب
- URL مقصد API از مدل/ارائه‌دهنده تأییدشده مشتق می‌شود؛ آدرس دلخواه کاربر به درخواست شبکه افزوده نمی‌شود.
- مدیریت مدل و کلید فقط از API احراز هویت‌شده ادمین مجاز است. کلیدها در خروجی مدیریت برگردانده نمی‌شوند.
- برای نصب مجدد، `ai_models.py` و `ai_fal_video.py` به پوشه runtime و سرویس پردازش منتقل شوند.
- کدهای تنظیم و مدل‌ها بدون کلید یا قابلیت تأییدشده در محیط عملیاتی اجرا نمی‌شوند. قبل از روشن کردن تولید ویدیو، یک آزمایش موفق روی حساب ارائه‌دهنده لازم است.
- وضعیت این نسخه: **شاخه توسعه؛ بدون اجرای تست واقعی API و بدون انتشار روی سرور اصلی**.
