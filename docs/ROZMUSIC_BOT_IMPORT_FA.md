# واردسازی RozMusic و تشخیص ویدیوی ربات مسیحا

به درخواست مالک دارای مجوز RozMusic، محتوای قابل‌دسترسی نقشه سایت استخراج می‌شود.

## وضعیت و کاربرد
- نقشه سایت: https://rozmusic.com/sitemap.xml
- ثبت نام خواننده، نام آهنگ، متن ترانه و لینک MP3 در پلی‌لیست عمومی all
- آهنگ‌های ثبت‌شده تکراری وارد نمی‌شوند و مالک سیستمی هیچ امتیازی دریافت نمی‌کند.
- متن آهنگ تا ۳۰ هزار نویسه حفظ می‌شود؛ در ربات امکان نمایش متن کامل وجود دارد.
- فایل MP3 روی سرور VPN بارگیری و ذخیره نمی‌شود، لینک مستقیم منبع در ربات ارائه می‌شود.
- پلی‌لیست all صفحه‌بندی ۴۰‌تایی دارد.
- ویدیوها پس از انتخاب الزامی نوع سینمایی یا سریال پذیرفته می‌شوند و برای سریال فصل و قسمت اجباری است.

## اجرای واردسازی
با وجود مجوز لازم، روی سرور تازه بعد از نصب افزونه اجرا کنید:

    sudo systemctl enable --now masiha-rozmusic-import.service

در نصب یکپارچه نیز می‌توان متغیر محیطی MASIHA_ENABLE_ROZMUSIC=1 را فعال کرد.
به طور پیش‌فرض سرویس بدون رضایت مالک مجاز فعال نمی‌شود.

وضعیت:

    sudo python3 /opt/masiha-vpn-extension/rozmusic_importer.py status
    sudo journalctl -u masiha-rozmusic-import -n 35 --no-pager

توقف یا ازسرگیری:

    sudo systemctl stop masiha-rozmusic-import
    sudo systemctl start masiha-rozmusic-import

فیلدهای وضعیت شامل queued (کل URL)، pending (صف)، done (ثبت‌شده)، skipped (نامرتبط یا بدون MP3)، error (خطای دستیابی) و playlist_all (آهنگ‌های عمومی) هستند.

## پایداری و امنیت
- پردازش یک‌نخی با تأخیر حداقل ۱.۸ ثانیه و CPUWeight=10 و محدودیت RAM=230M.
- در HTTP 429/503 مکث می‌کند. تمام نتایج به‌صورت تدریجی در SQLite ثبت شده و بعد از قطع برق یا ارتباط مجدداً ادامه می‌یابد.
- سرویس سیستم‌عامل برای ادامه نیازی به SentinelX ندارد؛ لغو دسترسی مدیریت از راه دور، واردسازی را متوقف نمی‌کند.
- همه صفحه‌های نقشه سایت مربوط به ماه‌های مختلف هستند؛ تکمیل آرشیو چندساله ممکن است ساعت‌ها طول بکشد. فقط آهنگ‌های قابل استخراج و دارای لینک مجاز وارد می‌شوند.
- متن ترانه و لینک‌ها از منبع مجاز شما اخذ می‌شوند؛ استفاده از این سرویس روی سایت‌های دیگر نیاز به مجوز جداگانه دارد.
