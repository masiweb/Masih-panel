# مرکز مدیریت هوشمند کانال — دستور راه‌اندازی

رفتار پیش‌فرض **خاموش** است؛ هیچ پستی بدون تنظیم کانال، بررسی مجوزهای ربات و تأیید فرد مدیر منتشر نمی‌شود.

## مراحل اتصال

1. همان ربات فروش VPN را مدیر کانال مقصد کنید. مجوز ضروری کانال: **Post Messages**. اگر قرار است ویرایش یا حذف پست انجام شود، مجوزهای مرتبط جداگانه لازم می‌شوند؛ این نسخه به آن‌ها نیاز ندارد.
2. برای پاسخ AI در نظرات، یک **گروه گفت‌وگوی متصل** به کانال داشته باشید و ربات را عضو آن کنید. تنظیم Privacy Mode ربات باید اجازه دریافت پیام‌های موردنیاز را بدهد. این نسخه فقط منشن واقعی ربات و پیام پاسخ‌داده‌شده به پیام ربات را پردازش می‌کند.
3. داخل ربات: «منوی مدیریت ← مرکز هوشمند کانال ← تنظیم کانال». آیدی کانال مثل \`@ChannelName\` یا شناسه عددی کانال را وارد کنید.
4. «بررسی مجوزها» را بزنید. این دکمه با Telegram Bot API نوع کانال، مجوز انتشار و گروه گفت‌وگوی متصل را بررسی می‌کند. اگر تأیید نشد، انتشار فعال نمی‌شود.
5. یک مدل متنی فعال با API معتبر در قسمت مدیریت AI انتخاب کنید. از تنظیم \`ai_default_text_model\` استفاده می‌شود (یا \`channel_ai_model\` در تنظیمات اصلی در صورت وجود).
6. «فعال‌سازی» را بزنید. سیستم هر روز تا ۳ پیش‌نویس تولید می‌کند. هر پیش‌نویس به چت خصوصی **تمام مدیران ثبت‌شده** برای تأیید، ویرایش یا رد می‌رود.

## استقرار روی سرور (با دسترسی مدیر سیستم)

بعد از دریافت نسخه جدید پروژه در سرور اصلی، از **ریشه مخزن پروژه** نصب را اجرا کنید. اسکریپت فایل‌های قبلی را پشتیبان می‌گیرد و پیش از اعمال تغییرات، بررسی نحوی و تست‌های مستقل را اجرا می‌کند.

~~~bash
cd /root/Masih-panel
git pull --ff-only origin main
sudo bash deploy/install-channel-manager.sh
sudo systemctl status masiha-channel-manager.timer --no-pager
sudo journalctl -u masiha-channel-manager.service -n 40 --no-pager
~~~

سرویس زمان‌بند جدا از پردازشگر اصلی تلگرام اجرا می‌شود تا درخواست‌های کاربران در زمان تولید محتوای AI کند نشود. انتشار تا زمان تنظیم و تأیید کانال همچنان غیرفعال می‌ماند.

## قوانین

- منطقه زمانی زمان‌بندی: \`Asia/Tehran\`. ساعت‌ها: ۱۰:۰۰، ۱۵:۰۰ و ۲۰:۳۰.
- حداکثر ۳ پست در هر روز تقویمی. **بدون تأیید مدیر، پستی وارد صف انتشار نمی‌شود**.
- تأیید پس از ساعت تعیین‌شده، انتشار در اولین اجرای زمان‌بند همان روز را ممکن می‌کند؛ نوبت روز گذشته منقضی می‌شود.
- بازنشر اتوماتیک پست‌های ردشده ممنوع است.
- هر پیام AI در گروه فقط در پاسخ به منشن @BotUsername یا Reply به خود ربات، با محدودیت ۵ پاسخ برای هر کاربر در ۲۴ ساعت و ۳۰ پاسخ در کل روز پذیرفته می‌شود.
- پرسش‌های شخصی درباره پرداخت، حساب، تاریخچه گفتگو یا اطلاعات اشتراک باید به چت خصوصی ربات ارجاع داده شوند.
- برای کاهش خطر انتشار اشتباه، این نسخه **فقط متن** منتشر می‌کند؛ تصویر و ویدیو بدون طراحی مسیر بررسی و تأیید رسانه، خودکار منتشر نمی‌شوند.
- اگر دسترسی مدیر کانال تغییر کند، مجوزها باید دوباره تأیید شوند؛ بررسی اعتبار هر ۲۴ ساعت لازم است.
- ارسال موفق پست از طریق \`outbox.done=1\` پیگیری می‌شود. اگر ارسال ناموفق شود، وضعیت پست \`failed\` می‌شود و بررسی مدیر نیاز است.
